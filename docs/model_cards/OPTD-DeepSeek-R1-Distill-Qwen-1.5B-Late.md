# OPTD-DeepSeek-R1-Distill-Qwen-1.5B-Late

[arXiv](https://arxiv.org/abs/2610.28048) · [Hugging Face Paper](https://huggingface.co/papers/2610.28048) · [All OPTD models](https://huggingface.co/collections/ModalityDance/optd)

An OPTD model trained from [deepseek-ai/DeepSeek-R1-Distill-Qwen-1.5B](https://huggingface.co/deepseek-ai/DeepSeek-R1-Distill-Qwen-1.5B) with specialists in **mathematics and coding**. This is a complete model that can be used directly for text generation.

OPTD teaches a student both the teacher’s final prediction and how its predictions change across layers, using responses generated by the student. This checkpoint accompanies *On-Policy Transition Distillation*.

**Late** identifies the placement of transition supervision during training. Mid and Late use different sets of layers; these names do not denote release versions or a quality ranking.

Use the model’s **native reasoning chat template**, supplied with its tokenizer.

## Quick start

Install PyTorch for your hardware, Transformers, and Accelerate:

```bash
python -m pip install torch transformers accelerate
```

The example below uses BF16. Teacher models and the OPTD training framework are not required for inference.

```python
import torch
from transformers import AutoModelForCausalLM, AutoTokenizer

model_id = "ModalityDance/OPTD-DeepSeek-R1-Distill-Qwen-1.5B-Late"
tokenizer = AutoTokenizer.from_pretrained(model_id)
model = AutoModelForCausalLM.from_pretrained(
    model_id, torch_dtype=torch.bfloat16, device_map="auto"
)
messages = [{"role": "user", "content": "Solve 2x + 5 = 17."}]
text = tokenizer.apply_chat_template(
    messages, tokenize=False, add_generation_prompt=True
)
inputs = tokenizer(text, add_special_tokens=False, return_tensors="pt").to(model.device)
with torch.inference_mode():
    output = model.generate(
        **inputs, max_new_tokens=1024, do_sample=True, temperature=0.7, top_p=0.95
    )
response = output[0, inputs.input_ids.shape[-1]:]
print(tokenizer.decode(response, skip_special_tokens=True))
```

The short generation limit is for the example. Paper evaluation uses benchmark-specific token limits and sample counts.

## Training and release details

<details>
<summary>Configuration and file contents</summary>

- Student initialization: `deepseek-ai/DeepSeek-R1-Distill-Qwen-1.5B`.
- Training updates: 150.
- Intermediate layers (zero-based): 11 / 15 / 19.
- Training domains: mathematics and coding.
- Full BF16 safetensors weights, tokenizer, and generation configuration are included.
- `training_metadata.json` records the training configuration; `checksums.json` records checkpoint/tokenizer SHA256 hashes.
- Optimizer state is not included.

</details>
